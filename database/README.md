# Scripts de base de datos

El perfil activo de persistencia usa SQL Server. Ejecuta los archivos de **sqlserver** del 00 al 03, en orden, con SSMS o sqlcmd. El esquema y los procedimientos se pueden aplicar sobre la entrega anterior. HU08 agrega la ficha sensorial y la referencia al evento. La conexión, las credenciales locales y la prueba JDBC se describen en [Conexiones](../docs/CONEXIONES.md).

Esta carpeta contiene definiciones y datos de ejemplo versionables. SQL Server administra los archivos de datos fuera del repositorio. Las carpetas migrations y dev contienen SQL histórico de PostgreSQL de la primera versión. Para la demo en memoria basta con iniciar el JAR.
